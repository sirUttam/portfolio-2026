# Portfolio - Full Stack Developer

A full-stack personal portfolio built using React (Vite) for the frontend and Node.js + Express for the backend.  
It includes a working contact form that sends emails using Gmail SMTP via Nodemailer.

---

## Features

- Responsive portfolio UI
- Contact form with real email sending functionality
- Backend API using Express
- Form validation and loading states
- Clean client-server architecture

---

## Tech Stack

### Frontend
- React (Vite)
- JavaScript (ES6+)
- CSS / Tailwind (if used)

### Backend
- Node.js
- Express.js
- Nodemailer (Gmail SMTP)
- CORS
- dotenv
