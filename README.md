# Personal Portfolio Website

A modern, responsive personal portfolio built using React and Vite.  
Designed with a clean dark theme and minimal neon accent styling for a professional developer presentation.

---

## Features

- Fast and optimized React + Vite setup  
- Modern UI with dark theme and subtle accent color (#84CC16)  
- Smooth and minimal animations for better user experience  
- Fully responsive design for mobile and desktop  
- Component-based architecture for maintainability  
- Interactive landing page with custom cursor and visual effects  
- Dedicated sections for projects, skills, and contact information  

---

## Tech Stack

- React  
- Vite  
- JavaScript (ES6+)  
- CSS / Tailwind CSS (if used)  
- Framer Motion (for animations)  
- React Icons
